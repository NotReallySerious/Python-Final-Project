# Python Final Project – Hospital Management System

## 📖 Overview
This repository contains our **Python Final Project**, developed as part of coursework requirements for the **Python programming module at Asia Pacific University (APU)**.  

The project is a **Hospital Management System (HMS)** designed to streamline operations within a healthcare environment. It provides **role-based access control** for different staff members, ensuring that each user can perform tasks relevant to their responsibilities. By combining Python’s modular programming capabilities with structured data handling, the system demonstrates how software can improve efficiency, accuracy, and collaboration in hospital workflows.

Key highlights include:
- **Administrative control** for managing users and system settings  
- **Financial management** handled by accountants  
- **Billing and transactions** managed by cashiers  
- **Patient record management** for doctors  
- **Prescription and inventory management** for pharmacists  
- **Secure login system** ensuring authenticated access for all roles  

This project showcases both **academic learning** and **practical application** of programming concepts, while also emphasizing teamwork and collaborative development.
---

## 🧩 Features
- **Role-based Access**:
  - **Admin** – manage system settings and user accounts  
  - **Accountant** – handle financial records and transactions  
  - **Cashier** – process payments and customer billing  
  - **Doctor** – manage patient records and consultations  
  - **Pharmacist** – oversee prescriptions and inventory  
  - **Login System** – secure authentication for all roles
   
- **Modular Codebase** – organized into reusable functions and classes  
- **Error Handling** – robust exception management for stability  
- **User Interaction** – clear input/output prompts for usability  
- **Data Processing** – efficient handling of structured data  
- **Documentation** – inline comments and structured README for clarity
